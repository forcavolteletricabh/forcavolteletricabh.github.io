FORÇAVOLT — Site institucional

ANTES DE PUBLICAR
1. Abra index.html no navegador para conferir.
2. Troque https://www.seudominio.com.br/ no canonical e no JSON-LD pelo endereço final do site.
3. Confirme as cidades efetivamente atendidas.
4. As fotos do site são imagens ilustrativas externas; se quiser, substitua por fotos reais de serviços da FORÇAVOLT.
5. Não há depoimentos fictícios nem avaliações inventadas.

PUBLICAÇÃO GRATUITA COM GITHUB PAGES
1. Crie uma conta em https://github.com/.
2. Crie um repositório público chamado forcavolt-site.
3. Envie o arquivo index.html para a raiz do repositório.
4. Abra Settings > Pages.
5. Selecione Deploy from a branch, branch main e pasta /(root); salve.
6. Após a publicação, use o endereço exibido pelo GitHub Pages.
7. Atualize o canonical e o campo url do JSON-LD em index.html para o endereço publicado.
8. Opcionalmente, adicione o site ao Google Search Console e solicite a indexação.

IMPORTANTE
- A publicação pode ser gratuita, mas um domínio próprio normalmente custa à parte.
- A página não configura nem paga anúncios Google Ads automaticamente.
- SEO não garante posições específicas no Google.
